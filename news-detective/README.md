# News Detective

Double-click index.html in your browser, then set backend URL in the top-right control (defaults to http://localhost:8000).

## Screenshot

Add a `screenshot.gif` or `screenshot.png` here for repo previews.

## Local Preview

Run a simple static server if you prefer not to open the file directly:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080/news-detective/`.
